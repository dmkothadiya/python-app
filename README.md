# python-app

A tiny Python web application that serves a simple “Hello, Backstage!” page.

## Run

Requires Python 3. Run the application from this directory:

```powershell
python app.py
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000) in your browser. Press `Ctrl+C` in the terminal to stop the server.
